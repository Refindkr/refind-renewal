02
Key Features
auto_videocam

자율주행 실습 최적화

복잡한 환경에서도 정밀한 경로 탐색과 장애물 회피가 가능한 자율주행 알고리즘 실습 환경을 제공합니다.

map

SLAM & Navigation 지원

실시간 지도 생성(SLAM) 및 정밀한 위치 추정 기술을 통해 로봇 내비게이션의 전 과정을 직접 제어하고 실험할 수 있습니다.

hub

ROS 기반 오픈 플랫폼

Robot Operating System(ROS)과의 완벽한 호환성을 통해 방대한 오픈소스 라이브러리와 도구들을 즉시 활용할 수 있습니다.

home_mini

컴팩트한 실내 주행 설계

제한된 실내 연구실 환경에서도 효율적인 기동성을 발휘하도록 설계된 슬림하고 견고한 폼팩터를 자랑합니다.
