## ROHand

출처 URL·버전·본문 페이지는 `lib/rohandManuals.ts`에서 관리한다. 상세 페이지와 기존 비교표 아래에 원문 PDF 링크를 표시한다. 홍보 페이지보다 해당 모델 공식 매뉴얼을 우선했다.

| 모델 | 기준 매뉴얼 | 주요 수정 |
| --- | --- | --- |
| A001 | V1.3.3 | 30kg을 네 손가락 굴곡 상태 수동 하중으로 명확화, 관절과 자유도 구분 |
| A002 | V1.1.5 | 545→580g, 1.0→0.7초, 신전 능동력 0.45→0.5kgf, 치수 183/95/113mm |
| AP001 | V1.0.8 | 640→661g, 엄지 길이 113mm·손바닥 너비 83mm, CAN FD→CAN |
| AP002 | V1.0.1 | 신전 능동력 0.5→0.45kgf, CAN FD→CAN, 손가락 샘플링 ≥50Hz |

무게는 손목 포함 ±5g. 통신은 모델 변형에 따라 다르며 -C는 CAN 버전. A002와 Lite 치수 그림은 해당 PDF에 포함된 원본 그림을 추출해 교체했다. AP003은 공식 매뉴얼을 확보하지 못해 검증 완료로 표시하지 않았으며 기존 수치를 유지했다.

## gForce Ultra

새 경로: `/products/physical-ai/gforce-ultra` (영문 `/eng` 접두사).

- 사용자 제공 `gForce Ultra.pdf` 1–2쪽을 기준으로 작성. 배포 사본: `/downloads/gforce-ultra.pdf`.
- 8채널 건식 EMG, 24-bit ADC, ADC 1,000Hz와 EMG 500Hz 구분.
- IMU 6축·50Hz. 현재 통신은 BLE 4.2. 기존 Pro+의 9축 사양을 복사하지 않음.
- 53×28×17mm, XS/S/M/L 밴드 190/202/216/230mm ±2mm, 200mAh, 작동 5시간, 정격 30mA.
- 사용자 제공 업그레이드 안내: 원시 EMG·제스처 결과 동시 출력, 범용 인식 모델, 추후 소프트웨어 개선.
- Bluetooth 5.0은 향후 하드웨어 개정 계획. 다중 동글·동기 수집은 적용 구성 확인이 필요하다고 표시.
- 제품 이미지: 제공 PDF 첫 페이지 렌더링. 기존 Pro+ 이미지를 Ultra로 재사용하지 않음.
- BCI/BMI 목록, 공통 메뉴, 사이트맵에 추가. 문의는 기존 네이버폼 사용.

검증: TypeScript 검사 통과. 로컬 Next 페이지 응답 및 화면 확인. 운영 배포 여부는 Git push/배포 결과로 별도 확인해야 한다.
