Ohandlite

1. 핵심 특징
제품명: 경량형 근전도 전자의수 (OhandLite)
무게: 363.5g (기존 Ohand 모델 약 500g 대비 약 27% 경량화)
- 상지절단장애인용 근전도 전자의수
- 손의 구조 및 동작 특성을 완벽하게 모방한 인공손
- 9개 동작 지정 가능(27개 동작 중 선택 가능)
- 2채널의 근전도 사용
- 기존 생체모방형 인공손에 비해 저렴한 가격
- 근전도 측정을 통한 동작 구현
- 인공지능 알고리즘을 통한 동작의도 파악 및 인공손 동작제어
- 전용앱을 통한 동작 제어 가능
- 전용앱을 통한 근전도 경계치 조절 가능
- 전용앱에서 2가지 모드/각 모드에서 3가지 그립동작 지정가능
- 모드변환은 손등의 버튼 누르면 변환가능
- 수동 손목회전 가능


2. 기능 및 조작 방식
기본적으로 Ohand 모델의 고성능 제어 기능을 유지하면서 무게를 줄인 버전으로, 다음의 기능을 포함하고 있습니다.


엄지위치
외측모드(Lateral Mode), 반대모드1(Opposed mode 1), 반대모드2(Opposed Mode 2)


외측 모드 (Lateral Mode)
주먹쥐기(FIST): 칫솔,포크,숟가락 등과 같은 막대 모양의 물체를 잡을 때 유용
마우스동작(Mouse): 마우스 사용, 클릭 동작 가능, 비바이오닉3 마우스 클릭과 유사
열쇠 집기(KEY): 카드, 종이, 열쇠 등 얇고 작은 물체 파지
포인트 : 키보드, 도어 벨 또는 리모컨과 같은 가벼운 물체를 클릭
컬럼(Column) : 사용자가 문과 같은 무거운 것을 밀거나, 버튼 누르기 가능. 단단한 버튼 누르는 동작 가능. 엘리베이터 버튼 윗옷 입을때 걸리지 않음.
접시 : 그릇 같은 물체 들고 있을 때
Salute : 자연스러운 손 모양
젓가락 : 젓가락 사용 시


반대 모드 1 (Opposed Mode 1): 
핀치(PINCH-Thumb-close): 냅킨, 초콜릿, 신발끈 등 얇은 물체 집기. 엄지가 가장 나중에 동작함. 엄지가 검지위에 위치함. 
핀치(Pinch-Thumb-Open): 엄지가 가장 나중에 동작함. 냅킨이나 초콜릿 또는 신발끈과 같은 얇은 물체 집을 때. 얇은 물체 집을 때. 엄지가 검지위에 위치함.
핀치(Pinch-index-thumb-open) : 엄지와 검지가 동시에 나중에 동작함. 냅키닝나 초콜릿 또는 신발끈과 같은 얇은 물체 집을때. 엄지끝과 검지끝이 맞닿음.
파워 : 무거운 물체 집을 때
쥐기(GRASP): 일반적인 물체 파지(약수,물병잡기 또는 둥근 물체)
들어올리기(Lift) : 가방이나 쇼핑백 같이 무거운 물건 들어올릴 때
접시(Plate) 접시나 책과 같은 평평한 물체 잡을 때


반대 모드 2 (Opposed Mode 2): 세 손가락 파지(Tripod) 등
세손가락 집기(TRIPOD-index-close): 머그잔, 컵 등을 세 손가락으로 안정적으로 파지. 검지와 중지가 가장 마지막에 닫힘
세손가락 집기(Tripod-index-open): 검지와 중지가 가장 마지막에 닫힘. 세 손가락으로 막대 모양 물체 집을 때
세손가락 집기(Tripod-Thumb-close) : 엄지손가락이 가장 나중에 닫힘. 세 손가락으로 막대 모양 물체 집을때. 머그잔이나 컵
세손가락 집기(Tripod-Thumb-open) : 엄지가 가장 마지막에 닫힘. 세 손가락으로 막대 모양 물체 집을때
세 손가락 집기(Tripod-index-thumb-open) : 엄지,검지,중지가 동시에 마지막에 닫힘. 세 손가락으로 막대 모양 물체, 지퍼 탭 및 신발끈 잡을때
파워(POWER) : 무거운 물체 잡을 때
쥐기(Grasp) 악수, 물병, 또는 기타 물체 잡을 때
물건들기(Lift) : 가방이나, 쇼핑백 같이 무거운 물건을 들어 올릴 때
접시(Plate) 접시나 책과 같은 평평한 물체 잡을 때


엄지 위치 조절: 사용 목적에 따라 엄지 손가락의 위치를 수동 또는 자동으로 최적화하여 다양한 파지 형태 구현 가능
근전도(EMG) 센서 제어: 사용자의 근위축 신호를 감지하여 직관적으로 의수 동작을 제어

3. 활용 사례 (Use Cases)
피로 감소: 장시간 의수를 착용하고 외부 활동을 해야 하는 직장인 또는 학생
일상 활동: 가벼운 물건 집기, 타이핑, 문 열기 등 일상적인 동작 수행
신체적 부담 최소화: 근력이 약한 고령자나 장시간 착용이 필요한 사용자에게 적합
